# Table Familiale

Application familiale halal : menus de 31 jours, recettes et ingrédients modifiables, liste M&S chaque semaine, commandes viande et poisson en début de mois et suivi des dépenses sur plafond initial de 850 £.

Le code source complet sera importé par le workflow de préparation et vérifié par les tests automatisés avant publication GitHub Pages.
